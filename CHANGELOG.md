## [0.1.0] — 2026-09-19

### Added

- Cursor plugin manifest (`.cursor-plugin/plugin.json`) for `openllm-orchestrator`.
- Stdio MCP config (`mcp.json`) running official `openllm mcp` with `${OPENLLM_API_KEY}` and `${OPENLLM_CLOUD_ORIGIN}`.
- Skills: getting-started, openllm-connect, openllm-dashboard, openllm-dev-task, grok-bot-orchestrator.
- Always-on rule: OpenLLM is model fabric; the agent remains the orchestrator.
- Commands: `/setup-openllm`, `/openllm-dev-task`.
- Architecture and Grok Bot owner docs.
- MIT license and marketplace logo.
